# beginner_expense_sheet
A simple expense sheet that I build as my first project in C language. It is a basic expense sheet with basic features like adding, deleting, updating, viewing and summarizing expenses. It can also save the expenses in the computer for future use.

<br><br>
Other than that I used my own knowledge and skills to write the code itself.
As a beginner I couldn't figure out some problems like proper input handling, use of dynamic memory allocation, and some other features, but I'm constantly improving myself and in the next project I learn to use these features.
